A — Modal centrée (actuel)

Modal avec suggestions + dropdown override. Bloque la vue table. Un mouvement à la fois. Simple mais lent pour traiter 20+ mouvements non catégorisés.

B — Inline expandable (pills cliquables)

La ligne se déplie dans la table. Suggestions en pills cliquables (1 clic = catégorisé). Navigation Préc/Suiv pour enchaîner. Pas de modal, pas de contexte perdu. Rapide pour traiter en batch.

C — Mode batch (traitement en masse)

Vue dédiée listant tous les non-catégorisés. Suggestions pré-remplies avec checkbox. "Appliquer suggestions" en 1 clic pour les haute confiance. Dropdown manuel pour le reste. Idéal syndic pro traitant des dizaines de mouvements.

Recommandation : B + C combinés

  • B (inline) pour catégoriser au fil de l'eau dans la vue table
  • C (batch) accessible via le bandeau alerte "X non catégorisés" pour traitement mensuel
  • Le syndic choisit son workflow selon le contexte

Trade-offs

  • A : modal bloquante, lente pour 20+ mouvements
  • B seul : bien au fil de l'eau, pas optimal pour rattrapage mensuel
  • C seul : overkill pour 1-2 mouvements ponctuels
