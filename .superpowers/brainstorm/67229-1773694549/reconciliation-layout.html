C — Hybride (table + mode rapprochement)

Vue table par défaut (comme l'actuel). Bascule en "mode rapprochement" split-screen filtré sur les non-rapprochés uniquement. Bouton "Valider tout" pour les auto-matchs haute confiance. Le meilleur des deux mondes.

Recommandation : C (Hybride)

  • Conserve la vue table existante pour consultation
  • Split-screen dédié pour le workflow rapprochement
  • "Valider tout" pour traiter les auto-matchs en batch
  • Filtre auto sur non-rapprochés = moins de bruit

Trade-offs

  • A : plus simple mais vision limitée, pas standard marché
  • B : standard mais remplace la vue table utile au quotidien
  • C : plus de code mais UX optimale pour syndic pro
