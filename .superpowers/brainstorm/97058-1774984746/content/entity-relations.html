Modèle de données unifié — CoProFlex

Architecture "mix" : données opérationnelles dans les tables métier, mouvements financiers dans le journal comptable

Principe clé : le journal comptable comme source unique

Les montants opérationnels (devis, contrat) restent dans leurs tables métier.
Dès qu'un euro bouge vraiment (appel émis, paiement reçu, facture validée) → écriture au journal.
Le solde d'un lot = vue calculée depuis le journal. Jamais stocké, toujours calculé.

Priorité : module Ventes (aucune table Supabase)
