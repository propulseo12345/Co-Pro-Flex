Section 9
Règles — Do / Don't
✓ DO
Utiliser les variables CSS de globals.css
Couleurs sémantiques saturées (-500/-600)
Borders ultra-subtiles (rgba 0.04 à 0.12)
Labels en UPPERCASE + letter-spacing
font-variant-numeric: tabular-nums pour montants
translateY(-1px) + shadow sur hover cliquables
Padding généreux (24px) dans les cards
✕ DON'T
Couleurs hardcodées quand une variable existe
Borders opaques (1px solid #xxx)
box-shadow au repos sur les cards
#F1F5F9 pour text-main → utiliser #e2e8f0
Styles inline (style={{}})
Couleurs pastel pour montants financiers
Font-size en rem dans Finance → utiliser px
